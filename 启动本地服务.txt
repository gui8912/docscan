启动本地服务
========================================

一、用途
--------
为本目录的「澄文扫描台」启动一个只监听 127.0.0.1 的本地静态服务，
让浏览器通过 http://127.0.0.1:8765/ 打开页面。
必须走 HTTP：直接用 file:// 打开会被同源策略挡住 PDF.js 的 worker，
导出前自检也会被跳过。

二、文件清单
------------
serve.bat                 本脚本（纯 ASCII 提示，Windows 批处理）
serve.js                  项目自带的零依赖 Node 静态服务（推荐）
启动本地服务.txt           本说明
README.md                 完整使用说明（环境、参数、已知限制）
index.html / app.js / core.js / pdfout.js / styles.css   程序主体
vendor/                   本地 PDF.js 3.11.174（Apache 2.0）

三、使用方法
------------
1. 双击 serve.bat；或在命令行执行 node serve.js。
2. 浏览器打开 http://127.0.0.1:8765/。
   若浏览器比服务先打开、显示「无法访问」，刷新一次即可。
3. 想换端口：先设环境变量再运行，例如
   命令行执行  set PORT=8766 && node serve.js
   或在 PowerShell 里  $env:PORT=8766; node serve.js
   注意 localStorage 按「协议+主机+端口」隔离，8765 与 8766 是两套独立设定。
4. 停止服务：在命令行窗口按 Ctrl+C。

四、原理与步骤
--------------
1. 脚本先检查 PATH 里有没有 node；有则执行 node serve.js。
   serve.js 负责 MIME 类型、no-cache、路径边界校验、
   拒绝隐藏文件与控制字符、404 统一返回纯文本，安全性完整。
2. 没有 Node 才回退 python -m http.server，并先确认 python 存在。
   该回退只提供最基础的目录浏览，不具备上述边界防护，仅供应急。
3. 两者都没有时打印提示并退出，不会静默失败。
4. PORT 用「未定义才设默认值」的方式，不会覆盖你事先设定的环境变量。

五、重要提醒
------------
· 本脚本本身刻意只用英文提示：Windows 批处理对 UTF-8/GBK 与
  CRLF 极其敏感，带 BOM 会让首行崩掉，裸 LF 会把多行连成一行，
  中文提示在 cmd 里会乱码。中文说明一律放在本文件。
· 服务只绑定 127.0.0.1，不对外网开放；不要改成 0.0.0.0。
· 请勿在服务的目录下放私密文件：虽然已拦截以点开头的隐藏文件，
  但目录内其它文件仍可通过 URL 读取。
· 「导出可覆盖源文件」是不可撤销操作，重要档案请先另存原件备份。

六、根治与备份建议
------------------
· 建议直接安装 Node.js（>=16）并始终走 node serve.js 或 npm start，
  避免 Python 回退路径的功能差异。
· 若要长期一键启动，可把本目录登记到 D:\Tools\服务台\services.json，
  用 C:\Program Files\nodejs\node.exe 执行 serve.js（当前已登记）。
· 源码已托管到 GitHub 私有仓库 gui8912/docscan（分支 main），
  重装系统或换笔记本时 git clone 后即可直接运行。
